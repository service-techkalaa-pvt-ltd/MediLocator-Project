How to Upload Medicines

  1. Download the sample template file below
  2. Fill in your medicine details following the format
  3. Save the file as CSV or Excel (.xlsx)
  4. Upload the file using the form below
  5. Review the validation results before final submission

Required Column Format

Column Name Required Format/Example
medicine_name ✓ Yes Paracetamol 500mg
generic_name No Acetaminophen
category No Pain Relief, Antibiotics, Vitamins, etc.
price ✓ Yes 50.00 (numbers only, no ₹ symbol)
quantity ✓ Yes 100 (whole numbers only)
description No For fever and pain relief

Important Rules

  • File must be CSV or Excel (.xlsx) format only
  • Column names must match exactly (case-insensitive): medicine_name, generic_name, category, price, quantity, description
  • First row must be headers, data starts from row 2
  • Price and quantity must be numbers (no special characters)
  • Maximum 500 medicines per upload
  • Duplicate medicines will be skipped (check by medicine_name)
